# forest_base friction log

Snags hit while building forest_base and its `litter` set (scripted route, headless only). Each entry: what happened, the fix, minutes lost, and whether the skill changed.

1. **A forest floor cannot touch the border.** Tileable layers sample in world space, so any slot change at the hex border (a tint or a different set) shows as a straight line against the meadow. Fix: the cap is one mesh in three slots split per face along two wavy contours: an untinted `grass` rim identical to `meadow_base_cap`, a dark mossy `grass` edge band, and the `litter` floor inside. Both contours get their own CDT points in every LOD (lattice points within 0.45 spacing of a contour are dropped), so the boundary follows the contour instead of zigzagging along the lattice, and the rim exists at LOD1/LOD2 too. The generator asserts that every border-touching cap face is rim. Lost: about 5 min of design. Skill: folded into `pitfalls.md` ("Biome bases").
2. **Forest-forest seams show a grass strip.** A grass rim is the only seam-safe edge for a single base mesh, so two forest tiles meet with about 2-7 m of grass between their floors. The PRD-sanctioned fix is a socket-chosen edge piece (PRD §6: grass blend) that lays litter over the rim when the neighbour is also Forest. Not built here (out of scope); reported as open. Skill: noted in the same pitfall.
3. **Shader nodes for leaf litter.** Leaf litter needs leaf shapes, which nodes cannot draw (oak friction 11), and a sliced 4D Voronoi reads as dots. Fix: `mat_litter.py` draws the tile in numpy (stamps placed with wrap-around indices, noise as FFT band-limited white noise, normal from the periodic height field), so it is periodic by construction: mirror correlation 0.016 / -0.001. First pass read as camouflage (moss blobs pasted on top, leaves like seeds); moss became a ground layer the litter partly covers, and the leaves got broader and denser. Lost: about 10 min. Skill: `pitfalls.md` (Tileable sets) now names the numpy route.
4. **The worktree hook refuses `magick` with parenthesised sub-images.** The 2x2 and 8x8 previews were refused as "too complex to verify". Fix: a small PIL script (`tilepreview.py` pattern) run as one plain command. Lost: about 2 min. Skill: added to the SKILL.md worktree rule.
