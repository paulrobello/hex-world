# rock_small friction log

1. **Texel density below 256 px/m at 512².** The first rock (1.24 x 1.0 m, buried to −0.32 m) measured a 241 px/m median, then 250 px/m with a tighter UV margin. The piece class allows 1.5 MB per family, so 1024² maps were not an option. The fix was a 1.2 x 0.9 m rock whose faces below −0.27 m are cut before the unwrap, which gave 271 px/m. Lost about 8 minutes. Skill: `project.md`, "Budgets", now has a Props paragraph on 512² atlases and the area limit.
2. **The 6-view render shows no textures.** `make kit-renders` renders the GLB, which embeds no images, so the first look at the bake came out flat grey. I bound the stage PNGs in a throwaway headless EEVEE still (`target/`, not committed) and judged the albedo from that. Lost about 5 minutes. Skill: a new `pitfalls.md` entry, "The 6-view render is untextured".
3. **Props float in the kit scenario.** `finish_kit` places every piece at y = 0, but the meadow relief dips to −0.25 m. I added `Placement.y` to `kit_scene.rs`, set from `meadow_base.py`'s `relief()` at each prop's spot. Lost about 5 minutes. Skill: a new `pitfalls.md` entry, "Kit-scenario props need a height".
4. **The worktree hook refused compound commands.** A chain with `git status`, and a heredoc followed by `cargo build`, were both refused. The skill already covers this ("Worktree sessions"), so no change was needed. Lost about 1 minute.
5. **The look needed two passes.** The first bake read as a smooth pale cushion with sparse, oversized specks. The second pass added 11 cleave planes instead of 8, a weaker smoothing pass, a lopsided shoulder, a deeper fine relief, finer specks, weathering streaks and chartreuse lichen (ref-2). This was normal iteration, so no skill change was needed. Lost about 10 minutes.
