# river_mouth_center friction

Shared helper `scripts/blender/kit/_mouth_dress.py` (also used by `river_mouth_l_center`). Scripted route, headless only.

1. **Grass-edge pebble groups mostly failed to place (about 4 min).** The first layout took `beach_center`'s group rule: an anchor at a random along-coast coordinate in ±12 m, then items scattered around it. On the mouth tile the channel cuts the beach in two and the edge-2 shoulder is a thin wedge, so most anchors fell outside the 1.5 m border band or inside the channel. Only 1 of 9 land pebbles was placed. LOD0 came out at 718 tris, and LOD2 (108) broke the 15 % ratio. Fix: `placements.group` now finds each group's anchor by rejection on its target shoulder, then scatters the rest. The build is 836 / 380 / 108. Skill fold: none needed. The rule "anchor groups by rejection on the reachable region" is local to this helper, and `beach_center` still works with its own rule.
2. **No reeds on the edge-2 bank (0 min, a layout fact).** On the edge-2 side (Blender y < 0 at rotation 0), s = 0.866 x + 0.5 |y|. At the reed distance (about 5 m from the centre line), s ≤ -8 needs x ≤ -12.1. That is inside the edge-3 band (1.5 m border plus the 1 m `river_edge` stub). So all three reed clumps stand on the edge-5 bank. The edge-2 shoulder also has no grass edge inside the border band. Its tuft and pebble group stands on the upper sand (s from -9.8 to -4), with one shorter log (1.1 to 1.5 m, yaw within ±45°). Recorded as a PLAN deviation in the dispatch report. Skill fold: none needed, because it is geometry specific to this tile.
3. **The worktree-isolation hook refused chained commands (about 2 min).** A heredoc file write chained with `make kit-build` was refused, and so was a `sed` with a shell variable path. Each file is now written with the Write tool, and each make target runs as one plain command. This is already in `SKILL.md` ("Worktree sessions"), so no change is needed.
