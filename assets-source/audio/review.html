Hex World audio review

Every mastered cue, played from the committed runtime files (Opus in WebM, AAC m4a fallback). Numbers are measured on the WebM by make audio-master. Loop cues have a gapless Web Audio player that loops at the manifest loop points, as the game will; the plain player's loop attribute can gap between repeats in some browsers. Serve the repo root over http (python3 -m http.server) for the gapless player.
