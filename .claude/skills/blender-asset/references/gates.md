# Gates

"Pinned by" names the test that enforces each check:
- `kit_gate::*` tests live in `crates/hex-play/tests/kit_gate.rs`. They read committed files only and run in CI through `make test`, and alone through `make kit-check`.
- `test_*` names are Blender tests (`make blender-test`, local only).
- `.mjs` tests: `kit-provenance.test.mjs` and `kit-lib.test.mjs` run in `make ui-test` (so `make checkall` and CI); `kit-compress.test.mjs` needs the KTX tools and runs only in `make kit-compress-test` (local, which also runs `kit-provenance.test.mjs`).
