# photo-mode

- **Use:** plays while photo mode is open (D7). The world pauses and the player frames shots.
- **Length:** about 3:00. **BPM:** 72, rubato and free-flowing. **Key:** G major. **Loop:** yes.
- **Role:** still, reflective and wondrous, with almost no rhythm, so composing a shot feels calm.

## Style
```
ambient neoclassical, gentle and reflective, slow felt piano chords, soft celesta, glass harmonics, warm string pads, distant music box, very sparse, no beat, dreamy and still, golden hour over a miniature world, 72 bpm rubato, G major, instrumental, loopable, very soft dynamics, lush reverb
```

## Exclude
```
vocals, choir, drums, percussion, bass drops, edm, dark ambient, horror, drone noise, big crescendo, fade out
```

## Lyrics / structure
```
[Instrumental]
[Intro: single sustained pad, a few soft piano notes]
[Verse: slow piano chords, celesta sparkles drift in]
[Interlude: glass harmonics and music box quote a rising five-note motif, slowly]
[Verse 2: strings breathe in softly under the piano]
[Outro: return to the opening pad and piano, same stillness, no ending]
```
